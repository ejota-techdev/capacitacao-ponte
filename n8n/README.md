# Fluxos do n8n

Exporte cada fluxo pelo menu **…** → **Download** e salve aqui com um nome claro:
`leads-gravar.json`, `leads-listar.json`, `resumo-semanal.json`, `agente-atendimento.json`.

Antes do commit, abra o arquivo e confira que não há token, senha ou URL de webhook escritos nos nós.
As credenciais ficam só no n8n.
